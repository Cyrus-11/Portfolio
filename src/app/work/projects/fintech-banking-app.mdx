## Overview

This project brings connected bank accounts, balances, transaction histories, and account insights into a banking dashboard.

**Stack:** Next.js, TypeScript, Appwrite, Plaid, and Dwolla.

## What I built

- A dashboard for connected accounts and balances.
- Transaction history views and financial charts.
- Server-side authentication and protected routes.
- Bank integrations using Plaid and Dwolla.
- Reusable interface components and backend actions.

## Organizing the application

The implementation separates reusable interface components from backend actions. Components provide the dashboard views, while backend actions support the application workflows and integrations.

Authentication and route protection are part of that structure, alongside the account and transaction views.

## Engineering focus

This project brought together interface development, authentication, and financial service integrations. The emphasis was on keeping the workflows maintainable as the dashboard combined several kinds of account information.
