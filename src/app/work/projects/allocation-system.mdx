## Overview

The Allocation System supports accommodation applications from registration through allocation-status tracking. It also provides admin workflows for managing profiles, room inventory, allocations, and releases.

**Stack:** Node.js, Express.js, MySQL, Sequelize, and JWT.

## Applicant workflows

I built registration, email verification, accommodation applications, and allocation-status views. These give applicants a path from creating an account to checking the state of an application.

## Administration and APIs

I developed APIs and admin workflows for managing profiles and room inventory, allocating accommodation, and releasing allocations. MySQL and Sequelize support the application's relational data.

## Authentication and validation

The implementation includes password hashing, JWT authentication, and request validation. Email verification uses six-digit one-time codes that expire after five minutes.

## Engineering focus

The project combines applicant and admin workflows around the same accommodation process. Registration, verification, applications, inventory, and allocation status each have a defined part in that process.
