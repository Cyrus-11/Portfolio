## Overview

ECO Agent Skills is a collection of reusable instructions for AI-assisted software work. I created five skills covering planning, session context, reviews, recovery, and UI documentation.

**Format:** Markdown and SKILL.md packages.

## What I built

- Planning instructions that define acceptance criteria before implementation.
- Session context instructions for saving decisions and continuing work across sessions.
- Review workflows that ask for evidence against the agreed requirements.
- Recovery instructions for resuming work after an interruption or failed approach.
- UI documentation instructions for recording interface decisions.

## Making expectations explicit

The collection puts recurring expectations into reusable files. Acceptance criteria describe what completion means, while the review workflow asks the agent to connect its conclusions to evidence.

Context saving addresses a different problem: the next session needs the decisions and outstanding work from the previous one. The skills give that handoff a defined place in the workflow.

## Packaging and validation

I packaged the skills in SKILL.md format with installation instructions and structural validation checks. Those checks cover the package structure; assessing the quality of the resulting work still requires a review of the implementation and its evidence.
