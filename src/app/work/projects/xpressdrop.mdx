## Overview

XpressDrop is a laundry logistics platform. I work on the backend and coordinate development as a Software Engineer and Project Manager, a role I started in July 2025.

**Stack:** Node.js, Express.js, TypeScript, Sequelize, MySQL, JWT, and Postman.

[Visit XpressDrop](https://usexpressdrop.com)

## Backend engineering

I develop APIs for authentication, orders, and vendor management. The implementation includes JWT access control, request validation, and relational models for users, vendors, and orders.

These APIs support the application workflows shared by the client applications and backend. My work includes collaborating with Flutter and Next.js developers on integration and resolving defects as the pieces come together.

## Testing and integration

I work with the team on Postman testing and API integration. Reviewing requests and responses together helps us identify whether an issue comes from validation, access control, application state, or the way a client consumes the API.

## Coordinating delivery

Alongside implementation, I coordinate priorities and development tasks across engineering, design, and QA. That includes connecting feature requirements to the work needed for integration, defect resolution, and delivery.

- JWT access control, request validation, and relational data modeling.
- API integration and defect resolution with Flutter and Next.js developers.
- Postman testing and coordination across engineering, design, and QA.
